# Reporting security issues

Use this repository's **Security → Report a vulnerability** form for private
reports. Do not post credentials, chat transcripts, or private source in issues.

Fuse runs local agent CLIs that can read and change project files according to
their configured permissions. Only open repositories you trust and review agent
permission requests. Provider credentials are managed by the provider's CLI.

Signed installer releases will be distributed only through this repository's
GitHub Releases. Until the first release, builds from source are development builds.
